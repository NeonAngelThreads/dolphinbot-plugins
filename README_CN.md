# dolphinbot-plugins
当前可用的 DolphinBot 的所有插件：

| 插件名称            | 插件类型      | 描述                                 | 依赖的插件        | 受支持的dolphinbot版本            | 下载链接                                                      |
|-----------------|-----------|------------------------------------|--------------|-----------------------------|-----------------------------------------------------------|
| `Actions Lib`   | **依赖库插件** | 原版 MC 的移动/交互模拟依赖库插件。               | -            | dolphinbot >= 1.7.0 Release | [`actions-core`](./actions-core/Actions-core-v26.0.1.jar) |
| `Pearl Gateway` | **功能插件**      | 将末影珍珠留在多个指定水槽位置，供多名玩家使用，作为回家的快捷方式。 | Actions Core |          dolphinbot >= 1.7.0 Release                   |                                                           |
