# dolphinbot-plugins
All plugins for DolphinBot that currently available:

| Plugin          | Type       | Description                                                                                         | Dependency   | Supported client    | Download                                                  |
|-----------------|------------|-----------------------------------------------------------------------------------------------------|--------------|---------------------|-----------------------------------------------------------|
| `Actions Lib`   | Library    | Movements/Interactions simulation provider for vanilla MC.                                          | -            | dolphinbot >= 1.7.0 | [`actions-core`](./actions-core/Actions-core-v26.0.1.jar) |
| `Pearl Gateway` | Functional | Leaving Ender Pearls at designated slots for multiple players to use as a quick way to return home. | Actions Core | dolphinbot >= 1.7.0 |                                                           |


# Share Your Plugin

Want to show off your own interesting plug-ins on the Bilibili channel? Welcome to contact me via private message at [bilibili@颜控小帕](https://space.bilibili.com/386644641).
